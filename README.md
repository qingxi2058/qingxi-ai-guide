## 📖 项目介绍

这是一个面向AI小白的工具导航站，汇集了最实用的AI工具教程、底层逻辑、资料库和学习路径，帮助普通人快速上手AI、用AI提效赚钱。

### 包含内容

- 🛠️ **P0 工具教程**：热门AI工具保姆级教程（Claude、NotebookLM、Cursor等）
- 🧠 **P1 底层逻辑**：AI时代必懂的核心认知
- 📚 **P2 资料库**：精选AI学习资源合集
- 🗺️ **P3 学习路径**：从小白到高手的进阶地图
- 📕 **P4 书单订阅**：AI从业者必读书单
